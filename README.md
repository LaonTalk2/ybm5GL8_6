# Lesson 8 · What Does He Look Like?    YBM(최희경) 영어 5학년 8단원 — 6차시 Wrap Up 미션 평가 앱

`L8_(6차시)종합평가wrapup_app (7) 공유.html`

외부 프로그램 설치 없이 **브라우저에서 파일을 더블클릭해 여는 것만으로 바로 실행되는** 단일 HTML 파일입니다. 5학년 Lesson 8(외모 묘사 표현)의 6차시 Wrap Up 활동을, 듣기 → 읽기 → 쓰기 → 말하기 순서의 미션 형태로 평가하고 결과를 자동으로 기록해 줍니다.

## 한눈에 보기

- 총 **21문항 / 30점** 만점 (듣기 4, 읽기 3, 쓰기 10, 말하기 4)
- 문제를 풀 때마다 즉시 채점·피드백이 나오고, 정답을 맞히면 색종이 애니메이션과 효과음이 나옵니다
- 마지막에는 영역별 점수, 취약 영역 안내, 문항별 응답 기록, **명예의 전당(Hall of Fame) 1~30위** 순위표가 표시됩니다
- 교사 모드(오른쪽 위 버튼)에서 PIN으로 들어가 문항을 직접 수정하고, 학생 기록을 표로 확인·CSV로 내려받을 수 있습니다
- 인물 그림은 코드로 직접 그리는 SVG 아바타(웹툰풍)이며, 머리 길이·모양·색, 눈 색, 피부색, 옷 종류·색, 안경, 모자를 다양하게 조합할 수 있어 다문화 교육 취지도 반영했습니다

## 학생용 진행 순서

1. 첫 화면에서 학년·반 / 번호 / 이름을 입력하고 **미션 시작하기**
2. 4개 영역을 순서대로 진행 (진행 중 상단 스탬프 띠에서 완료 영역을 확인 가능)

| 영역 | 문항 수 | 유형 |
|---|---|---|
| 듣기 (Listen) | 4 | TTS로 문장을 들려주고 그림/설명 고르기. `🔊 듣기`, `🐢 천천히`, 음성이 안 나올 때를 대비한 `문장 보기(교사용)` 버튼 제공 |
| 읽기 (Read) | 3 | 캐릭터 소개 카드 T/F 판정, 글을 읽고 인물 찾기 |
| 쓰기 (Write) | 10 | 뜻-영어 연결하기, 어순 고르기, 첫 글자 쓰기, 문장 언스크램블, 낱말 받아쓰기(스펠링) |
| 말하기 (Speak) | 4 | 보기 낱말을 눌러 문장을 완성한 뒤 마이크로 말하기(문장 1점 + 발화 1점). 음성 인식이 안 되는 환경에서는 "직접 확인"으로 대체 채점. 2회 틀리면 정답 예시를 들려주고 다음 문제로 진행해 학생이 막히지 않도록 설계됨 |

3. 모든 문항을 마치면 결과 화면에서 총점, 영역별 점수, 부족한 영역 안내, 명예의 전당, 문항별 응답이 표시됩니다.

## 교사 모드

- 첫 화면 오른쪽 위 **교사 모드** 버튼 → PIN 입력 (기본값 `1234`, 교사 모드 내 **설정** 탭에서 변경 가능)
- **문제 편집**: 안내문, 들려줄 영어 문장, 보기, 정답, 아바타 외형(드롭다운 즉시 미리보기)까지 모든 문항을 수정·추가·삭제 가능. 하단 **변경 사항 저장**을 눌러야 학생 화면에 반영됨
- **학생 기록**: 제출한 학생의 학반·번호·이름·영역별 점수·총점을 표로 확인, **CSV로 내보내기**, **전체 삭제** 가능. 행마다 "문항별" 버튼으로 개별 응답 상세 확인
- **설정**: PIN 변경, 편집한 문제를 기본값으로 되돌리기, 현재 브라우저가 사용 중인 영어 음성 확인

## 저장 방식 · 주의사항

- 문항 데이터, 설정(PIN), 학생 기록, 명예의 전당 기록은 앱을 여는 브라우저의 `localStorage`에 저장됩니다(별도 서버·DB 없음). 단, 이 앱이 특정 플랫폼(교사가 배포하는 호스팅 환경 등)의 `window.storage` API 위에서 열리면 그쪽 저장소를 우선 사용하도록 되어 있어, **같은 앱을 함께 쓰는 모든 학생·교사에게 기록과 문제 수정 내용이 공유**됩니다. 한 학급 단위로 동일한 방식(같은 URL 또는 같은 PC)으로 사용하는 것을 권장합니다.
- 로컬 파일을 그냥 더블클릭해 각자 PC/브라우저에서 열면 기록은 그 브라우저에만 남고 공유되지 않습니다.
- 브라우저 캐시·사이트 데이터를 지우면 저장된 기록·문항 수정 내용이 사라질 수 있습니다.

## 권장 실행 환경

- **Microsoft Edge** 권장 — 자연스러운 영어 TTS 음성(예: Microsoft Online Natural 음성)이 기본 포함되어 있어 한국어 음성이 영어 문장을 잘못 읽는 문제를 피할 수 있습니다. 영어 음성이 없는 브라우저에서는 설정(Windows) → 시간 및 언어 → 음성에서 English(United States) 음성을 추가해야 합니다.
- 말하기 영역의 자동 음성 인식은 **Web Speech API(SpeechRecognition)**를 지원하는 브라우저(Chrome, Edge)와 마이크 권한 허용이 필요합니다. 지원되지 않으면 "직접 확인" 버튼으로 교사/학생이 자체 판단해 채점할 수 있습니다.
- 인터넷 연결 없이도 문제 풀이 자체는 가능하지만, 브라우저의 TTS·음성 인식 엔진이 온라인 음성을 쓰는 경우 해당 기능만 제한될 수 있습니다.

## 파일 구조

- 의존성 없는 순수 HTML/CSS/JavaScript **단일 파일**(외부 라이브러리 호출 없음)
- 인물 그림은 이미지 파일이 아니라 코드로 그리는 **인라인 SVG**라서 화질 저하 없이 확대되고, 외형 옵션 변경도 코드(교사 모드 드롭다운) 값만 바꾸면 즉시 반영됨
